# Reliable references and coherent assistant instructions

The user prioritizes broken references and requires a fluent system prompt rather than accumulated warnings. The [failure trace](../research/2026-10-19-reference-reliability.md) identifies model copying of transport identities; the [behavior-driven contract](../specs/2026-10-14-behavior-driven-tools.md) retains strict canonical identity and current reads. The earlier [coherence plan](2026-10-15-coherent-assistant-instructions.md) governs the full prompt rewrite.

## Design

Wrap the actual model backend in a request-local translation boundary. The controller, knowledge adapters, persisted calls/results/answers and navigation remain canonical. Long model-facing evidence and inventory-location references become typed aliases such as `ref:7ac21f09.c.3` and `slot:7ac21f09.c.1`: one random eight-hex process nonce and monotonic base36 request/entry counters avoid reuse within the backend instance. Readable canonical evidence references of at most 32 characters remain unchanged. Aliases are locators, not authorization; every underlying live validation still runs.

Translate only defined reference fields and supported citation syntax. This includes a JEI payload's `viewerHandle` only when it exactly matches that record's source handle, and typed slot fields inside the defined storage `owners` and `entries` structures. Do not rewrite guide prose, item IDs, owner fingerprints, arbitrary provenance, counts or cursors. Register only identities in accepted tool output, preserve the output ceiling after encoding and bound retained state without silent eviction. Verify exact wire replay before substituting retained canonical results. Streaming expansion must be correct at every token split and preserve web annotation ranges, steering and cancellation behavior. Unknown, altered, wrong-kind and prior-request aliases remain unresolved; no guessed correction is allowed.

Rewrite `GroundingInstructions.INSTRUCTIONS` as one ordered policy covering the player's goal and read-only boundary, claim-specific evidence, feasibility, focused reads and a useful answer. State each governing rule once. Preserve important source, coverage, inventory, recipe, reference, history, targeting and privacy contracts; remove repeated scenario warnings. A request-assembly test is not proof of model behavior.

The ATM10 relic question exposed `[native:ref:a6e39be8.1.j]`: a valid current-request alias wrapped in its provider qualifier. Translate this citation form only when the qualifier matches the exact canonical provider. Preserve wrong-provider, unknown, altered and previous-request aliases. Verify streamed text at every split and completed replay; do not broaden tool-argument decoding or infer missing Curios equipment support.

The live test exposed a saved JEI Markdown destination missing only its provider qualifier. Add a narrow rendering compatibility path for exact `jei/` handles already recorded in that same answer. Require one distinct provider/handle identity, provider `jei`, and scope-matching existing navigation; collisions, typos and target-only matches stay unbound. This repairs the known saved representation without rewriting history or weakening tool validation. Luna owns only `ScreenText.java` and `ScreenTextTest.java` from this specified contract, with parent-owned RED/GREEN runs and installed old-answer navigation proof.
