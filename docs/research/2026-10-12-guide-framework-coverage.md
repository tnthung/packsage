# Guide framework coverage: Minecraft 1.21.1 NeoForge

Date: 2026-10-12

Scope: a bounded first-party source check of twenty representative content mods targeting Minecraft 1.21.1 on NeoForge. Selection covers recognizable tech, magic, farming and storage mods, including the user's examples; it is not a measured top-twenty ranking by active players. This is a framework inventory, not an exhaustive code audit or measured page/recipe-coverage count. “Confirmed” means the linked publisher or versioned repository source identifies the documentation path. “Not identified” means this check did not establish a shipped framework; it is not proof that no documentation exists.

These rows distinguish a framework’s potential reach from measured coverage. A confirmed framework does not imply that every machine, recipe, progression rule, or custom page is extractable through generic APIs. Optional Patchouli/GuideME books count only when installed and enabled; a fallback viewer may expose ordinary text while an additive adapter handles framework-specific semantics.

## Coverage summary

| Result | Count | Mods |
| --- | --- | --- |
| Confirmed Patchouli guide/book content | 8 | Industrial Foregoing, PneumaticCraft, Ars Nouveau, Mystical Agriculture, Productive Bees, Iron's Spells, Nature's Aura, Ender IO |
| Confirmed GuideME | 3 | AE2, Modern Industrialization, recent Powah |
| Confirmed Modonomicon | 1 | Occultism |
| Confirmed Ponder | 1 | Create |
| Own manual/booklet | 2 | Immersive Engineering, Actually Additions |
| Shipped shared guide framework not established | 5 | Mekanism, Refined Storage, Sophisticated Backpacks, Storage Drawers, Farmer's Delight |

Eight confirmed users out of this selected twenty is 40% potential framework reach. It is not a prevalence estimate for all popular mods or a claim that 40% of all their knowledge is extractable. Some guides are optional, individual pages may be opaque, and the five unestablished cases are not proven universal negatives. A mod can still be useful through native data, JEI, quests, config inspection and external sources without a Patchouli guide.

For PackSage, this supports Patchouli as an early shared documentation adapter while showing the additional value of GuideME, Modonomicon and Ponder. It does not settle their global priority from this small sample. Measure actual installed/enabled books, pages, provider versions and supported/partial/opaque extraction on the fixture and real-pack checks.

Patchouli documents common text, recipe, item, entity and multiblock page fields, alongside templates and other extension paths. The generic adapter can target those common fields; a shared framework does not remove provider-specific semantics or custom rendering. [Default page types](https://vazkiimods.github.io/Patchouli/docs/patchouli-basics/page-types/).
