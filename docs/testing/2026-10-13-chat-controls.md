# Chat controls player checks

Date: 2026-10-13

Restart Minecraft with the installed update. No terminal or JAR-copy steps are required.

1. In Settings, choose Enter and check Enter sends while Shift+Enter inserts a newline. Choose Ctrl+Enter and check plain Enter inserts a newline while Ctrl+Enter sends. Set Sessions before Show more to four or five, return to chat and check each group's collapsed count. Confirm both choices survive restarting.
2. Check the six controls above the composer have equal compact widths. Narrow the window or increase GUI scale, then grow a multiline draft: controls should wrap above the input without overlap. Open Model/Effort, select values, scroll longer lists and dismiss them by clicking outside or pressing Escape.
3. Use Copy on a user question and an assistant response, then paste into the input. Edit the latest question, change it and resend. The finished exchange should replace the previous one; reopen the session and check no duplicate remains. Earlier exchanges and another world's read-only session should not offer editing.
4. Hover the context bar. Check allowance, estimated usage and included message count. Change history quotas and check the green/red avatar indicators change together for both sides of each exchange. Failed/cancelled exchanges should be excluded. A published model capacity limits the allowance; missing provider metadata is shown as unknown. These are conservative replay estimates, not billing counts.
5. Check the New chat plus is centered. Extra gameplay/screenshot context should appear beside the other composer controls, with details on hover, rather than at the conversation's top. Check token labels and Copy/Edit controls stay inside the message area.

Automated checks cover HTTP 503 recovery, retry exhaustion/cancellation and continuation reuse. A persistent provider outage may still produce an error after the single retry; the latest failed exchange can be edited and resent.
