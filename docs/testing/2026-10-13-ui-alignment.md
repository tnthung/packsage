# UI alignment player checks

Date: 2026-10-13

After restarting Minecraft with the installed update:

1. Check New chat, Search/Screenshot, input placeholders, message bubbles, inline chips, sidebar rows and Back. Text blocks should be centered inside their boxes. Search/Screenshot icons should be visibly smaller and centered beside their labels.
2. Type one line, then several wrapped lines. Check the composer text, caret placement and clicking between rows. Send a short message and a wrapped message; compare their top/bottom padding.
3. Open Settings. The account card should be shorter, align with the model rows and leave a clear gutter before the scrollbar. Its provider icon, two-line status and account action should form a centered group.
4. Check selected/unselected model and effort radios. The outline should be smooth, with a filled center dot for the selected choice. Repeat at another Minecraft GUI scale and in a narrower window; check the stacked account action remains inside the card.

These are visual checks. The assistant runs all automated checks and builds; no terminal or JAR-copy steps are required from the player.
